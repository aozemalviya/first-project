# Employee Payroll Management System

## Problem Statement

Managing employee salary information manually can take time and may lead to calculation mistakes. This project provides a simple way to store employee details, record attendance and calculate salary.

## Project Scope

The system is designed for basic employee and payroll management. It can store employee information, calculate attendance percentage, calculate salary and search for employees.

## Target Users

- Small businesses
- Offices
- HR staff
- Students learning Python

## Main Features

- Add and display employee details
- Calculate attendance percentage
- Calculate gross salary
- Search employee records
- Save employee data
- Test the payroll calculations

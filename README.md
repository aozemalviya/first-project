# Employee Payroll Management System

## Overview
This project is a simple Employee Payroll Management System.  
It helps an admin store employee details, calculate monthly salary, generate payslips, and view basic reports.
The system reduces manual calculation errors and keeps employee and salary data in one place.

## Features
- Admin login
- Add, view, update, and delete employee records
- Calculate salary (basic pay + allowances - deductions)
- Generate payslip
- View monthly / employee reports
- Manage attendance 
- Input validation and simple error messages

## Major Modules
1. Employee Management
2. Attendance Management
3. Salary Calculation
4. Payroll and Slip Generation
